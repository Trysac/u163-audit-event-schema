# Security Policy and Threat Model. ## Design Limits: The schema denies attributes containing case-insensitive substrings: 'password', 'passwd', 'secret', 'token', 'authorization', 'cookie', 'api_key', 'private_key'. ## Defended Threats: Secret leakage in attribute keys. Denial of Service (DoS) via oversized payloads: from_json imposes a 16,384 byte limit and traps recursion errors. Error leakage: Exception messages name the field path and rule, never echoing potentially sensitive inputs. ## Not Defended: Accidental leaks in unstructured attribute values. ## Logging: The library initializes a NullHandler and does not perform application logging.
