# audit-event-schema. A strict audit event model with canonical JSON: who did what to which target with what outcome, validated fields, UTC millisecond time, and refusal of sensitive attribute names. ## Installation: pip install audit-event-schema. ## Usage: from datetime import datetime, timezone. from audit_event_schema import Actor, Target, new_event, to_json. evt = new_event(actor=Actor('user', 'u-1'), action='invoice.update', target=Target('invoice', 'inv-9'), outcome='success', clock=lambda: datetime(2026, 11, 6, 12, 0, 0, 123456, tzinfo=timezone.utc), id_factory=lambda: 'evt-1'). print(to_json(evt)). ## Public API: The library exposes Actor, Target, and AuditEvent as frozen dataclasses. It provides factories and utilities: new_event, to_json, and from_json. It includes JSON_SCHEMA for validation against the Draft 2020-12 spec. Errors: AuditEventError (ValueError subclass) handles validation failures. ## Why not alternatives: Unlike free-form structured logs, this package enforces a strict, versioned event shape with a canonical encoding, enabling consistent parsing and consumption across different services.
